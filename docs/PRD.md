# PRD — 감정 리셋 60s (터치 기반)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 프로젝트명 | toss-mini-calm-60s |
| 형태 | Toss 미니앱 (WebView) |
| 기술 | React + TypeScript + Vite |
| 디자인시스템 | @toss/tds-mobile |
| 서버 | 없음 (로컬 저장) |
| AI | 없음 |
| 목표 | 빠른 출시 + 빠른 지표 검증 + 얇아 보이지 않는 5페이지 UX |

---

## 1. 제품 한 줄 정의

사용자가 다양한 감정 상태에서 60초 안에 터치 기반 리셋 미션을 수행하고,
완료 기록을 누적하여 재방문하게 만드는 미니앱.

---

## 2. 타겟 감정 (6개 고정)

Home에서 감정 선택. 감정은 "기록/추천"을 위한 분류이며 의료적 진단이 아니다.

- 불안
- 짜증
- 무기력
- 집중 안됨
- 긴장됨
- 다운됨(우울감)

---

## 3. 핵심 문제 / 해결 방식

### 문제
- 심호흡 앱은 거부감이 있고("호흡하라"가 부담)
- 단일 터치 미션만 있으면 콘텐츠가 얇아 보임(5페이지 구성인데 기능이 빈약)

### 해결
- 호흡 대신 "터치 기반 미션"으로 진입 장벽 낮춤
- 미션을 3종류 제공하여 콘텐츠 폭 확보
- 감정별 추천 미션으로 선택 고민 최소화

---

## 4. 전체 페이지 구조 (총 5페이지)

설정 페이지는 제외. 대신 "모드 선택"을 별도 페이지로 두어 콘텐츠 두께 확보.

| 페이지 | 설명 | 탭 노출 |
|--------|------|---------|
| Home | 감정 선택 + 시작 진입 | ✅ |
| Mode Select | 3개 터치 미션 선택(감정별 추천 포함) | ❌ |
| Session | 선택한 미션 실행(실제 60초 리셋) | ❌ |
| Complete | 액션 선택 + "완료 기록하기"(저장 트리거) | ❌ |
| History | 최근 7일 기록 + 감정/모드 통계 | ✅ |

### 하단 탭
- Home / History (2탭)
- 토스 앱과 동일한 플로팅 형태로 구현
- Mode Select, Session, Complete는 플로우 화면(탭 비노출)

---

## 5. 핵심 미션 3종 (터치 기반, 60초 수준)

### Mission A) Slow Tap (진정형)

| 항목 | 내용 |
|------|------|
| 목적 | 과자극 없이 안정감 |
| 룰 | 2초 간격 가이드로 "천천히 터치" |
| 목표 | 30회 (60초 근처가 되도록 설계) |
| 완료 조건 | 카운트 30 도달 또는 60초 도달 시 자동 완료(선택) |
| 추천 감정 | 불안 / 긴장됨 / 다운됨 |
| 특이사항 | 너무 빨리 누르면 "천천히" 안내(패널티는 최소) |

### Mission B) Hold & Release (안정형)

| 항목 | 내용 |
|------|------|
| 목적 | 리듬을 강제해 감정 끊기 |
| 룰 | 누르고 유지(4초) → 놓고 대기(2초) 반복 |
| 목표 | 10회 반복 (총 60초) |
| 완료 조건 | 10회 완료 |
| 추천 감정 | 짜증 / 긴장됨 |
| 특이사항 | WebView long-press 충돌 방지를 위해 "버튼 누르고 있는 동안 게이지 차는 방식"으로 구현 |

### Mission C) 3-2-1 Grounding Tap (집중 전환형)

| 항목 | 내용 |
|------|------|
| 목적 | 생각 과열/산만함을 즉시 끊고 현재로 복귀 |
| 룰 | 체크 리스트 탭으로 완료(터치 6회) |
| 체크항목 | 보이는 것 3개 → 들리는 것 2개 → 느껴지는 것 1개 |
| 완료 조건 | 총 6개 모두 체크 |
| 추천 감정 | 집중 안됨 / 불안 |
| 특이사항 | 60초를 꼭 채울 필요 없음. "짧은 성공 경험 + 기록" 목표 |

## 6. 각 페이지 상세 기획

### Page 1) Home

**목적:** 3초 내 세션 시작

**구성:**
- 타이틀: 지금, 60초만 리셋
- 감정 선택 6개 (라디오)
- 감정에 따라 "추천 모드" 1개 표시 (예: "추천: Slow Tap")
- CTA: 시작
- 오늘 통계: 오늘 완료 N회 / 연속 N일

**동작:**
- 감정 미선택 시: "감정을 선택해 주세요"
- 시작 클릭 시: Mode Select로 이동(추천 선택 상태로)

### Page 2) Mode Select

**목적:** 콘텐츠 두께 확보 + 선택 명확화

**구성:**
- 뒤로가기 버튼 + 선택한 감정 표시
- 타이틀: 어떤 방식으로 리셋할까요?
- 미션 카드 3개: Slow Tap(진정) / Hold & Release(안정) / 3-2-1(집중)
- 추천 태그 표시 (선택한 감정에 따라)
- CTA: 시작하기

**동작:**
- 모드 선택 후 시작 → Session으로 이동

### Page 3) Session

**목적:** 실행 집중 (이탈 최소)

**공통 구성:**
- 상단: 현재 감정 + 선택 모드
- 진행률 UI (ProgressBar)
- 가이드 문구
- 중단 버튼 (X)

**세부 동작 (모드별):**
- Slow Tap: 터치 카운트/가이드
- Hold: Press/Release 단계 텍스트 + 원형 게이지
- 3-2-1: 체크 진행 UI (6개 순차)

**완료 시:** 자동으로 Complete 페이지 이동
**중단 시:** 확인 후 Home으로 복귀 (저장 없음)

### Page 4) Complete

**목적:** "저장"과 "재방문 가치" 확정

**구성:**
- 완료 체크 아이콘
- 완료 문구: 좋아요, 여기까지 완료!
- 액션 선택 (택1, 선택사항): 물 마시기 / 창문 열기 / 10걸음 걷기
- CTA: 완료 기록하기 ← 저장 트리거
- Secondary: 한 번 더 (같은 모드로 재시작)

**저장 규칙 (중요):**
- 타이머 완료만으로 저장하지 않음
- "완료 기록하기" 클릭 시에만 저장

### Page 5) History

**목적:** 리텐션 (다시 들어올 이유)

**구성:**
- 연속 streak 카드 (그라데이션 배경)
- 최근 7일 기록 캘린더 형태 (날짜 / 완료 횟수)
- 감정별 사용 비율
- 모드별 사용 비율
- 기록 없을 때 빈 상태 UI

**데이터:** localStorage 기반

## 7. 저장 설계 (로컬 only)

**Storage Key:** `calm60_save_v1`

**기본 JSON 예시:**
```json
{
  "version": 1,
  "lastCompletedDate": "2026-01-22",
  "todayCount": 2,
  "streak": 3,
  "history": [
    { "date": "2026-01-16", "count": 1 },
    { "date": "2026-01-17", "count": 0 },
    { "date": "2026-01-18", "count": 2 }
  ],
  "moodStats": {
    "anxiety": 3,
    "anger": 1,
    "lethargy": 0,
    "focus": 2,
    "tension": 1,
    "down": 1
  },
  "modeStats": {
    "slow_tap": 4,
    "hold_release": 2,
    "grounding_321": 2
  }
}
```

**저장 로직 (요약):**
- 완료 기록 저장 시 (today 기준):
  - 같은 날짜면 todayCount++
  - 다른 날짜면 todayCount=1
- streak: lastCompletedDate가 어제면 streak++, 아니면 streak=1
- history: 오늘 entry 업데이트/추가, 최근 7일로 trim
- moodStats/modeStats: 해당 키 +1

## 10. "빠꾸 방지" 체크포인트

이 MVP가 얇아 보이지 않기 위한 조건:

- ✅ 페이지는 5개이지만 "실제 기능"이 3개 미션으로 분화되어 있음
- ✅ 감정 선택 + 추천 로직으로 개인화 느낌 제공
- ✅ History에서 누적이 보임
- ✅ 완료 저장은 명시 버튼으로 동작 (조작/오작동 감소)

---

## 11. 개발 우선순위 (최소 구현 순서)

1. ✅ 라우팅 (5페이지) + 하단 탭 (Home/History)
2. ✅ localStorage save/load + streak/todayCount/history
3. ✅ Mission A (Slow Tap)
4. ✅ Mission C (3-2-1)
5. ✅ Mission B (Hold & Release)
6. ✅ Complete 저장 + Stats 업데이트
7. ✅ History 감정/모드 통계
